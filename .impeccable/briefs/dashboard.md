# Surface brief — Dashboard (NOC-статусборд)

Scope: главный экран дашборда (view + edit режимы). Mode: Operate.
Audience: владелец homelab, ежедневный запуск, открытие сервисов и просмотр статусов.

## Direction contract

THESIS: Дашборд — экран дежурного инженера NOC: не витрина стеклянных карточек, а стена мониторинга, где главный контент — состояние сервисов крупной типографикой. Отказ от категоричного дефолта «стекло + градиент + неон-акцент».

OWN-WORLD: Почти чёрный матовый грунт (#0b0e11 dark / #eef1f4 light), off-white текст (#e8ecef), dim #8b949e. LED-статусы: #2ee6a8 (up), #ff5c5c (down), #ffb454 (warn/active). Акцент пользователя — редкий сигнальный цвет (по умолчанию #38c8ff): фокус, drag, active. Плоские блоки, 1px хайрлайны-разделители (#23282e), никакой глубины из теней — глубина из контраста и плотности. Цифры — monospace tabular; метки — system-ui caps с трекингом. Заголовки секций — display-смелость (крупно, uppercase, как табло).

STORY: Дежурный за секунду видит: все ли сервисы живы (LED), который час и погода (телеметрия в шапке), куда идти (крупное имя сервиса). Редактирование — «режим обслуживания»: можно двигать модули, ничего не мигает само.

FIRST VIEWPORT: Полоса телеметрии во всю ширину сверху: крупные mono-часы слева (48–64px), дата, погода справа; под ней — сетка статус-блоков во всю ширину вьюпорта: LED-точка, крупное имя сервиса (18–20px/600), хост мелким mono. Edit-полоса — тонкая телеметрическая строка сверху (не пилюли). Первичное действие — клик по блоку сервиса.

FORM: №4 из заземлённого списка «патч-панель» переиграна пиком «NOC-статусборд» (seed key 6142ef7e, выбор пользователя на странице решения). Челленджер-поднятия: tabular-цифры (ocean-dive), dim-внимание (streaming-wall), display-заголовки (emigre).

SIGNATURE INTERACTION: «Эскалация» — при перетаскивании карточки блок получает warn-рамку #ffb454 и мигание LED, остальные блоки мягко приглушаются до 60%Opacity; по отпусканию — все возвращаются. Тема переключается через View Transition как «смена смены».

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Constraints

- Русский UI, drag-n-drop сетка и все настройки через WebUI, light/dark, мобильный первоклассный — нерушимы (PRODUCT.md)
- Система тем остаётся фичей: 4 темы перезаписываются в грамматике NOC-мира (id меняются, fallback обновляется)
- Акцент остаётся пользовательски настраиваемым
